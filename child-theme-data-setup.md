# Alur Isi Data Child Theme Mobil3

## Customize

1. Isi **Customize Mobil Velocity**:

   1. **Site Identity**: logo, site title, tagline, welcome  text, site icon.
   2. **Header Image**
   3. **Widgets - Main Sidebar**: widget pencarian, widget text: title "promo" dan content promo \[velocity-produk style="list" jumlah="3" kategori="promo"], widget text: title dan content kontak kami, dan widget text: title "statistik pengunjung" dan content statistik \[velocity-statistics]
2. **Theme Color**: sesuaikan dengan warna logo

## Gallery

* Aktifkan fitur **Gallery Post Type** di Velocity Addon.
* Gunakan shortcode **VD Gallery** untuk tampilan halaman gallery.

## Logo Header

* Apabila warna logo tidak kontras dengan background belakangnya, berikan **background putih**.

## Data Produk

* Data Produk dapat disesuaikan dengan produk client (tidak harus mobil). Jika klien tidak mengirim produk bisa di isi contoh sesuai materi.



## Halaman Home

* Set halaman **Home** mengambil template **"Home Template"**.
* Tambahkan shortcode \[velocity-produk] di home dengan tampilkan maksimal 6 produk di home.
